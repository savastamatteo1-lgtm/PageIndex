  <name>Task 1: Implement PageIndex class with all public methods</name>
  <files>
    pageindex/api.py

  <action>
    Add the `PageIndex` class to `pageindex/api.py` (below the settings and return type definitions from Plan 01).

    **Constructor: `__init__(self, *, settings=None, **kwargs)`**
    Per CONTEXT.md: accepts either a pre-built `PageIndexSettings` object or individual kwargs that build one internally.
    - If `settings` is provided, use it directly
    - Otherwise, try `PageIndexSettings(**kwargs)` -- catch `pydantic.ValidationError` and re-raise as `ConfigError` with clear message listing missing fields (see RESEARCH.md "Fail-Fast Config Validation" pattern)
    - After settings are resolved, call `self._init_subsystems()`

    **`_init_subsystems(self)`** (private):
    Wire settings to existing singletons:
    1. **Supabase client (Pitfall 2):** Set `os.environ["SUPABASE_URL"]` and `os.environ["SUPABASE_KEY"]` from `self._settings.supabase.url` and `self._settings.supabase.key` BEFORE any DB access. Also reset the DB client singleton if it was already initialized (import `pageindex.db.client` and set `pageindex.db.client._client = None` to force re-initialization with new values). This handles the case where a second `PageIndex` instance uses different credentials.
    2. **LLM provider:** Import `pageindex.llm.provider` and replace the module-level `_provider_instance` with a new `LLMProvider` built from `self._settings.llm.model_dump()`. This bypasses `load_llm_config()` which reads config.yaml independently (Pitfall 1 avoidance).

    **`search(self, query: str, *, strategy: str = "auto", limit: int | None = None) -> SearchResponse`**
    - Import and call `pageindex.retrieval.strategy.search(query, strategy=strategy, limit=limit or self._settings.retrieval.default_top_k)`
    - Wrap with `time.perf_counter()` for timing measurement
    - Convert internal `pageindex.retrieval.models.SearchResponse` to public `SearchResponse`:
      - `results` = internal `.results`
      - `query` = the input query
      - `strategy_used` = internal `.strategy`
      - `scores` = `{"engine_gaps": internal.engine_gaps, "result_count": len(internal.results)}`
      - `timing` = elapsed time rounded to 3 decimal places
      - `reasoning` = internal `.reasoning`
    - Wrap all errors in `SearchError`

    **`search_semantic(self, query: str, *, limit: int | None = None) -> list`**
    - Delegate to `pageindex.retrieval.semantic.search_semantic(query, limit=limit or self._settings.retrieval.default_top_k)`
    - Wrap errors in `SearchError`

    **`search_metadata(self, query: str, *, limit: int | None = None) -> list`**
    - Delegate to `pageindex.retrieval.metadata.search_metadata(query, limit=limit or self._settings.retrieval.default_top_k)`
    - Wrap errors in `SearchError`

    **`search_tree(self, query: str, doc_ids: list[str], *, model: str | None = None) -> list`**
    - Delegate to `pageindex.retrieval.tree_search.tree_search_sync(doc_ids, query, model=model or self._settings.llm.completion_model)`
    - Wrap errors in `SearchError`

    **`ingest(self, *, path: str | None = None, text: str | None = None, url: str | None = None, additional_fields: dict | None = None) -> IngestionResult`**
    - Validate that exactly one of `path` or `text` is provided (raise `IngestionError` if neither or both)
    - If `path` is provided:
      - Call `pageindex.ingestion.stages.process_single_document(path, llm_provider=get_provider(), config=self._build_ingestion_config(), additional_fields=additional_fields)` -- check the exact signature of `process_single_document` and adapt accordingly
      - Build `IngestionResult` from the returned `DocumentPipeline` object
    - If `text` is provided: For v1, raise `IngestionError("Text ingestion not yet implemented -- use path= with a file")` since the underlying pipeline only supports file paths. Document that text ingestion is planned. Alternatively, if the ingestion pipeline supports it, wire it.
    - Pass `additional_fields` through to the DB layer if provided (Pitfall 6: document it as user-provided overflow, not auto-extracted)
    - Wrap all errors in `IngestionError`

    **`_build_ingestion_config(self) -> dict`** (private helper):
    Convert `self._settings.ingestion` to the dict format expected by `process_single_document`. Map `IngestionSettings` fields to the keys expected by the ingestion pipeline (inspect `stages.py` for exact parameter names).

    **`retrieve(self, doc_id: str) -> DocumentInfo`**
    - Call `pageindex.db.documents.get_document(doc_id)` for metadata
    - Call `pageindex.db.trees.get_tree(doc_id)` for tree structure
    - If document not found, raise `SearchError(f"Document not found: {doc_id}")`
    - Return `DocumentInfo(doc_id=doc_id, name=doc["doc_name"], metadata=doc, tree=tree)`
    - Chunks are NOT loaded by default (expensive). User can access them via `pageindex.db.chunks.get_chunks_by_doc()` directly.

    **`list_documents(self, *, limit: int = 100, offset: int = 0) -> list[dict]`**
    - Delegate to `pageindex.db.documents.list_documents(limit=limit, offset=offset)`
    - Convenience method for discovering available documents

    **IMPORTANT -- "Replace, don't wrap" principle (Pitfall 3):** The PageIndex class replaces the OLD public API surface (`page_index()` function), NOT the internal machinery. `page_index_main()` is still called by the ingestion pipeline internally and must NOT be removed. Only the user-facing `page_index()` convenience function at the bottom of `page_index.py` (lines 1103-1111) is superseded.

  <action>
    Modify `pageindex/db/client.py` to support resetting the singleton when credentials change. This is needed because `PageIndex.__init__()` sets env vars from its settings, but the singleton may have already been initialized with old values.

    Add a `reset_client()` function:
    ```python
    def reset_client() -> None:
        """Reset the cached Supabase client, forcing re-initialization on next get_client() call.

        Called by PageIndex.__init__() when new credentials are provided via constructor.
        """
        global _client
        _client = None
    ```

    This is the minimal change (Option (a) from RESEARCH.md Pitfall 2). The `PageIndex.__init__()` already sets `os.environ` before calling `reset_client()` + `get_client()`, so the existing `get_client()` logic picks up the new env vars.

    Do NOT change `get_client()`'s signature or behavior -- all existing code that calls `get_client()` continues to work unchanged.
  </action>
  <verify>

    Must succeed.
