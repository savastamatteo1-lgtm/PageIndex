<objective>
Build the metadata retrieval engine that translates natural language queries into structured JSON filters via LLM, validates them, and executes them as Supabase PostgREST filter chains.

Purpose: Users need to search the Italian legal corpus by structured criteria ("sentenze della Corte di Cassazione dal 2020") without anyone writing raw SQL. The LLM fills a flat JSON filter schema, the app validates it, and Supabase PostgREST handles the actual query.

Output: `pageindex/retrieval/prompts.py` (prompt builder + JSON schema) and `pageindex/retrieval/metadata.py` (filter generation, validation, query execution, scoring).
</objective>

<task type="auto">
  <name>Task 2: Create metadata retrieval engine</name>
  <files>
    pageindex/retrieval/metadata.py
  </files>
  <action>
Create `pageindex/retrieval/metadata.py` with the complete metadata search pipeline:

1. **generate_filters(query: str, model: str | None = None) -> MetadataFilter** function:
   - Uses `litellm.completion()` directly (same pattern as ingestion Stage 2 -- not provider.complete() -- because we need to pass `response_format`)
   - Passes `FILTER_JSON_SCHEMA` as `response_format` parameter
   - Passes `build_filter_system_prompt()` as system message, user query as user message
   - `temperature=0` for deterministic output
   - Parses response JSON via `json.loads()`
   - Validates by constructing `MetadataFilter.from_dict()` -- if this raises, it's a validation failure
   - On validation failure: rebuild prompt with `build_retry_prompt()` and retry (up to `METADATA_MAX_RETRIES` total attempts per locked decision)
   - Uses `@retry(wait=wait_random_exponential(min=1, max=30), stop=stop_after_attempt(3))` from tenacity for API-level retries (network errors, rate limits) INSIDE each attempt
   - Returns `MetadataFilter` on success
   - If all attempts fail, raise a clear error with the last validation error message

2. **build_metadata_query(filters: MetadataFilter, limit: int = DEFAULT_TOP_K) -> list[dict]** function:
   - Gets Supabase client via `get_client()`
   - Builds query chain on `client.table("documents").select("*")`
   - For each non-None field in filters (per RESEARCH.md Pattern 2):
     - `doc_type` -> `.ilike("doc_type", f"%{value}%")` (per locked decision: ilike for partial matching)
     - `date_from` -> `.gte("date", value)`
     - `date_to` -> `.lte("date", value)`
     - `authority` -> `.ilike("authority", f"%{value}%")`
     - `court_level` -> `.ilike("court_level", f"%{value}%")`
     - `legal_area` -> `.overlaps("legal_area", value)` (array overlap for implicit OR)
     - `ecli` -> `.ilike("ecli", f"%{value}%")`
     - `parties` -> cast to text and use ilike: `.filter("parties::text", "ilike", f"%{name}%")` for each party name (Pitfall 5 from RESEARCH.md)
   - `.limit(limit).execute()`
   - Returns `response.data`

3. **score_metadata_results(results: list[dict], filters: MetadataFilter) -> list[dict]** function:
   - Per locked decision: score = number of filter fields that matched / total non-null filter fields
   - For each document in results, check each non-null filter field against the document's actual values:
     - String fields: case-insensitive substring match (mirrors ilike behavior)
     - Date fields: check if document date is within range
     - Array fields (legal_area): check if any filter value appears in document array
     - Parties: check if party name appears in parties JSON text
   - Add `score` key to each result dict
   - Sort by score descending
   - Return scored results

4. **search_metadata(query: str, limit: int | None = None, model: str | None = None) -> list[MetadataResult]** function:
   - Main entry point combining all the above
   - Resolve model from parameter -> config.yaml -> default (same override chain as ingestion)
   - Call `generate_filters()` to get MetadataFilter
   - Call `build_metadata_query()` to get raw results
   - Call `score_metadata_results()` to add scores
   - Filter out results below METADATA_MIN_THRESHOLD from config
   - Convert to `MetadataResult` objects with `engine_name="metadata"`, `confidence` from `assign_confidence()`, `parsed_filters=filters.to_dict()`
   - If no results: return empty list (per locked decision: empty results return empty list)
   - Return list of MetadataResult

Import `get_client` from `pageindex.db.client`. Import from `pageindex.retrieval.models`, `.config`, `.prompts`. Use `logging.getLogger(__name__)` for logging.
