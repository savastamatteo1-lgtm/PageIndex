### Integration Notes on "partial" Wiring

Three requirements have partial integration — all are functional but have config-threading gaps:

- **FOUND-03 (partial):** LLM switching works for all subsystems except tree indexing, which uses legacy ConfigLoader reading top-level `model:` from config.yaml. Users CAN change the tree-indexing model by editing config.yaml directly — they just can't do it via `PageIndex(llm={...})` constructor override.

- **FOUND-05 (partial):** The public API works correctly. The issue is that docstring examples show flat kwargs (`supabase_url=...`) but the actual constructor requires nested dicts (`supabase={"url":...}`). The API itself is functional with correct syntax.

- **STRAT-01 (partial):** All 4 strategies work. The gap is that `PageIndexSettings.retrieval.rrf_k` and other tuning params are not forwarded to engines — they use config.yaml defaults. The `default_top_k` and `default_strategy` params ARE wired.

- **ENRICH-03 (partial):** Description search works and is accessible via `search(strategy="hybrid")` or via `from pageindex.retrieval import search_description`. The gap is that `PageIndex` class doesn't expose `search_description()` as a direct method like the other three engines.

### Integration Issues

**ISSUE-05 (LOW): Constructor docstring examples wrong**
`pageindex/__init__.py` and `utils.py` docstrings show `PageIndex(supabase_url=..., supabase_key=...)` — this syntax raises ConfigError. Correct syntax is `PageIndex(supabase={"url":..., "key":...})`.

**ISSUE-06 (LOW): RetrievalSettings fields not all wired**
`rrf_k`, `engine_weights`, `global_min_score`, `internal_fetch_multiplier` defined in `PageIndexSettings.retrieval` but not forwarded to engines. Only `default_top_k` and `default_strategy` are threaded through.

**ISSUE-07 (LOW): Tree-indexing model bypasses PageIndexSettings**
`stage_tree_index()` uses `ConfigLoader` reading top-level `model:` from config.yaml. The `LLMProvider` singleton replacement in `_init_subsystems()` doesn't affect tree indexing.

**ISSUE-08 (LOW): search_description() not on PageIndex class**
API asymmetry — three of four engine-specific methods exposed but not description search.

**ISSUE-09 (LOW): max_embedding_batch hardcoded**
`stages.py:232` hardcodes `_EMBED_BATCH_SIZE = 250` despite `IngestionSettings.max_embedding_batch` field existing.
