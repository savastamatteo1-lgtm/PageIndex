## Integration Issues

### ISSUE-01 (CRITICAL): Config Key Collision Crashes ingest()

**Path:** `pipeline.py:210` → `process_single_document` → `stage_tree_index` → `ConfigLoader._validate_keys()`

`pipeline_config` in `pipeline.py:210-218` includes ingestion-specific keys (`metadata_pages`, `chunk_max_tokens`, `chunk_overlap`) alongside tree-indexer keys (`if_add_node_id`, `if_add_node_text`, `if_add_node_summary`). This entire dict is passed to `stage_tree_index`, which feeds it to `ConfigLoader().load(merged)`. `ConfigLoader._validate_keys()` checks against top-level `config.yaml` keys — the ingestion keys are nested under `ingestion:`, not top-level, so it raises:

```
ValueError: Unknown config keys: {'metadata_pages', 'chunk_max_tokens', 'chunk_overlap'}
```

**Impact:** Every `ingest()` call crashes before processing any document.
**Affected requirements:** FOUND-04, and transitively SEM-01, ENRICH-01, ENRICH-02
**Fix complexity:** Low — separate ingestion keys from tree config before passing to `stage_tree_index`, and thread them as explicit arguments to `stage_chunk` and `stage_extract_metadata`.

### ISSUE-02 (SIGNIFICANT): description_embedding Never Written During Ingestion

**Path:** `stage_store` (Phase 2) → `documents.description_embedding` column (Phase 3 migration 003)

The ingestion pipeline stores `pipeline.description` as `doc_description` (text) in `stage_store`, but never computes or stores the embedding vector for `description_embedding`. Migration 003 adds this column, and `search_description()` queries it via `match_descriptions` RPC (which filters `WHERE d.description_embedding IS NOT NULL`). Result: freshly ingested documents always return zero results from `search_description()`.

`backfill_description_embeddings()` exists in `description.py` to handle this, but is never called automatically.

**Impact:** `search_description()` returns empty results for all newly ingested documents.
**Affected requirements:** ENRICH-02 (partial — text stored but not embedded), ENRICH-03 (broken E2E flow)
**Fix complexity:** Low — embed `pipeline.description` in `stage_embed` or after it, store in `stage_store`.

### ISSUE-03 (MINOR): retrieval: Section Absent from config.yaml

`load_retrieval_config()` in `retrieval/config.py` gracefully falls back to hardcoded defaults when the `retrieval:` section is missing from `config.yaml`. No runtime error, but users cannot tune retrieval parameters via config file.

### ISSUE-04 (MINOR): updated_at Bypasses _METADATA_COLUMNS Guard

`update_document()` in `documents.py` adds `updated_at` to the filtered dict after the `_METADATA_COLUMNS` guard, creating an implicit exception to the column allowlist contract. Functional but fragile.
