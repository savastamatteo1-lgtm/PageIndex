# Phase 3.1 Plan 01: Ingestion Integration Fixes Summary

**Config namespace separation fixing ingest() crash, plus description embedding wiring enabling search_description() on freshly ingested documents**

## Accomplishments
- Fixed ISSUE-01: Separated `pipeline_config` into `tree_config` (only valid ConfigLoader keys) and explicit ingestion params, eliminating the `ValueError: Unknown config keys` crash on every `ingest()` call
- Fixed ISSUE-02: Added `description_embedding` computation in `stage_embed` and storage path through `stage_store` and `_METADATA_COLUMNS`, enabling `search_description()` to return results for freshly ingested documents
- Resolved tech debt: config.yaml overrides for `metadata_pages`, `chunk_max_tokens`, `chunk_overlap` are now properly threaded to their target stages instead of being swallowed by function defaults

## Task Commits

Each task was committed atomically:

1. **Task 1: Separate config namespaces and thread ingestion params** - `c3fbc05` (fix)
2. **Task 2: Compute description embedding and wire storage path** - `06fc682` (feat)

## Files Created/Modified
- `pageindex/ingestion/pipeline.py` - Replaced `pipeline_config` with `tree_config`, updated `_process_with_rollback` and `executor.submit` signatures to forward ingestion params
- `pageindex/ingestion/stages.py` - Updated `process_single_document` to accept and thread ingestion params, added description embedding in `stage_embed`, added `description_embedding` write in `stage_store`
- `pageindex/ingestion/models.py` - Added `description_embedding: list[float] | None = None` field to `DocumentPipeline` dataclass
- `pageindex/db/documents.py` - Added `"description_embedding"` to `_METADATA_COLUMNS` allowlist

## Decisions Made
- Built `tree_config` as a whitelist of known ConfigLoader top-level keys (`if_add_node_id`, `if_add_node_text`, `if_add_node_summary`) rather than filtering the full dict -- prevents Pitfall 5 from RESEARCH.md
- Description embedding computed as a separate single-item `_embed_batch` call AFTER the chunk embedding loop -- avoids mixing with chunk batches (Pitfall 4)
- Guarded with `if pipeline.description:` to reject both None and empty string (Pitfall 3)
