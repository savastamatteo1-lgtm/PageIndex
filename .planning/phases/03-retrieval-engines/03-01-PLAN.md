<task type="auto">
  <name>Task 2: Create retrieval database migration</name>
  <files>
    pageindex/db/migrations/003_retrieval.sql
  </files>
  <action>
Create migration `003_retrieval.sql` with the following DDL:

1. **Enable pg_trgm extension:**
   ```sql
   CREATE EXTENSION IF NOT EXISTS pg_trgm;
   ```

2. **Add trigram GIN indexes** for fast ILIKE fuzzy matching (per locked decision -- no vocabulary coupling at query time):
   - `documents_doc_type_trgm_idx` on `doc_type` using `GIN (doc_type gin_trgm_ops)`
   - `documents_authority_trgm_idx` on `authority` using `GIN (authority gin_trgm_ops)`
   - `documents_court_level_trgm_idx` on `court_level` using `GIN (court_level gin_trgm_ops)`
   - `documents_ecli_trgm_idx` on `ecli` using `GIN (ecli gin_trgm_ops)`

   Note: The existing B-tree indexes from 001 can coexist -- B-tree for equality, GIN for ILIKE patterns.

3. **Add description_embedding column** to documents table:
   ```sql
   ALTER TABLE documents ADD COLUMN IF NOT EXISTS description_embedding vector(768);
   ```

4. **Create HNSW index** on description_embedding for fast cosine similarity:
   ```sql
   CREATE INDEX IF NOT EXISTS documents_desc_embedding_hnsw_idx
       ON documents USING hnsw (description_embedding vector_cosine_ops)
       WITH (m = 16, ef_construction = 64);
   ```

5. **Create match_descriptions RPC function** (per RESEARCH.md code example):
   - Parameters: `query_embedding vector(768)`, `match_threshold float DEFAULT 0.7`, `match_count int DEFAULT 10`
   - Returns: `doc_id UUID, doc_name TEXT, doc_description TEXT, similarity float`
   - Body: SELECT from documents WHERE description_embedding IS NOT NULL AND similarity > threshold, ORDER BY distance, LIMIT match_count
   - Use `1 - (d.description_embedding <=> query_embedding)` for cosine similarity (same pattern as match_chunks)

6. **Grant SELECT on new function** to `pageindex_readonly` role for defense-in-depth.

Add header comment block explaining the migration purpose: "Retrieval engine infrastructure: pg_trgm fuzzy indexes, description embedding column, and match_descriptions RPC."
