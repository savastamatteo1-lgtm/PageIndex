  <action>
Create `pageindex/db/migrations/001_initial_schema.sql` with the full DDL:

1. Enable pgvector extension: `CREATE EXTENSION IF NOT EXISTS vector WITH SCHEMA extensions;`

2. Create `documents` table with:
   - `doc_id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `doc_name TEXT NOT NULL` (document filename/identifier)
   - `doc_description TEXT` (LLM-generated description, populated in Phase 2)
   - Italian legal metadata -- all open TEXT, no hardcoded enums per user decision:
     - `doc_type TEXT` (sentenza, ordinanza, decreto, legge, etc.)
     - `date DATE` (document date)
     - `authority TEXT` (issuing authority)
     - `ecli TEXT` (European Case Law Identifier)
     - `gu_number TEXT` (Gazzetta Ufficiale number)
     - `legal_area TEXT[]` (array of legal sub-areas, per user decision for multi-area)
     - `parties JSONB DEFAULT '[]'::jsonb` (array of {name, role} objects)
     - `court_level TEXT` (Cassazione, Corte d'Appello, Tribunale, etc.)
     - `cross_references JSONB DEFAULT '[]'::jsonb` (array of {ref, source, type} objects)
   - `additional_fields JSONB DEFAULT '{}'::jsonb` (overflow only, per user decision)
   - `created_at TIMESTAMPTZ DEFAULT NOW()`, `updated_at TIMESTAMPTZ DEFAULT NOW()`

3. Create `document_trees` table with:
   - `tree_id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `doc_id UUID NOT NULL REFERENCES documents(doc_id) ON DELETE CASCADE`
   - `tree_json JSONB NOT NULL` (full tree structure from PageIndex)
   - `created_at TIMESTAMPTZ DEFAULT NOW()`
   - `UNIQUE(doc_id)` -- one tree per document

4. Create `chunks` table with:
   - `chunk_id UUID PRIMARY KEY DEFAULT gen_random_uuid()`
   - `doc_id UUID NOT NULL REFERENCES documents(doc_id) ON DELETE CASCADE`
   - `node_id TEXT` (node_id from tree structure for traceability)
   - `content TEXT NOT NULL` (chunk text)
   - `embedding vector(768)` (default dimension, configurable via migration regeneration)
   - `metadata JSONB DEFAULT '{}'::jsonb` (node title, start/end page, etc.)
   - `created_at TIMESTAMPTZ DEFAULT NOW()`

5. Create indexes:
   - HNSW: `chunks_embedding_hnsw_idx ON chunks USING hnsw (embedding vector_cosine_ops) WITH (m = 16, ef_construction = 64)`
   - GIN: `documents_parties_gin_idx ON documents USING GIN (parties)`
   - GIN: `documents_cross_refs_gin_idx ON documents USING GIN (cross_references)`
   - GIN: `documents_legal_area_idx ON documents USING GIN (legal_area)`
   - B-tree: `documents_doc_type_idx`, `documents_date_idx`, `documents_court_level_idx`, `documents_ecli_idx`

6. Create `match_chunks` RPC function for vector similarity search (cosine distance via `<=>` operator). Parameters: `query_embedding vector(768)`, `match_threshold float DEFAULT 0.7`, `match_count int DEFAULT 20`. Returns: chunk_id, doc_id, content, metadata, similarity.

7. Create read-only role `pageindex_readonly` with SELECT-only permissions on all public tables. Use `ALTER DEFAULT PRIVILEGES` so future tables also grant SELECT. Explicitly `REVOKE INSERT, UPDATE, DELETE`.

Also create `pageindex/schema/legal_vocabulary.yaml` documenting Italian legal conventions:
- `doc_types`: list of standard types (sentenza, ordinanza, decreto, legge, decreto legislativo, decreto legge, regolamento, circolare, parere, delibera, atto parlamentare) with brief Italian descriptions
- `legal_areas`: hierarchical taxonomy (diritto civile > obbligazioni, famiglia, successioni, reale; diritto penale > reati contro la persona, reati informatici, etc.; diritto amministrativo; diritto del lavoro; diritto commerciale; diritto tributario; diritto europeo; diritto processuale)
- `court_levels`: ordered hierarchy (Giudice di Pace, Tribunale, Corte d'Appello, Cassazione for ordinary; Corte Costituzionale for constitutional; TAR, Consiglio di Stato for administrative)
- `party_roles`: ricorrente, resistente, imputato, parte civile, pubblico ministero, interveniente, appellante, appellato
- `cross_reference_types`: legislation, case_law, regulation, eu_law, constitutional

Use standard Italian legal terminology throughout, not English translations. Include a comment at the top explaining this file is a reference for the LLM metadata extractor (Phase 2), not a database constraint.

Create `pageindex/db/__init__.py` that exports the key functions from all three modules:
```python
from .documents import insert_document, get_document, get_document_by_name, list_documents
from .chunks import insert_chunks, match_chunks, get_chunks_by_doc
from .trees import insert_tree, get_tree
```

Create `pageindex/db/client.py` with a singleton Supabase client:
- `get_client() -> Client`: Reads `SUPABASE_URL` and `SUPABASE_KEY` from environment variables. Caches the client in a module-level `_client` variable. Raises a clear error if env vars are missing.
- Import from `supabase import create_client, Client`.

Create `pageindex/db/documents.py` with typed document operations:
- `insert_document(doc_name: str, metadata: dict | None = None) -> dict`: Inserts a new document. `metadata` is a flat dict with optional keys matching the column names (doc_type, date, authority, ecli, gu_number, legal_area, parties, court_level, cross_references, additional_fields). Returns the full inserted row (including generated doc_id). Filter out None values from metadata before insert to let DB defaults apply.
- `get_document(doc_id: str) -> dict | None`: Retrieves a single document by UUID doc_id. Returns None if not found.
- `get_document_by_name(doc_name: str) -> dict | None`: Retrieves a document by doc_name. Returns first match or None.
- `list_documents(limit: int = 100, offset: int = 0) -> list[dict]`: Lists documents with pagination.

Create `pageindex/db/chunks.py` with chunk operations:
- `insert_chunks(chunks: list[dict]) -> list[dict]`: Batch inserts chunks. Each chunk dict has: `doc_id` (required), `content` (required), `embedding` (list[float], optional), `node_id` (optional), `metadata` (optional dict). Returns inserted rows.
- `get_chunks_by_doc(doc_id: str) -> list[dict]`: Gets all chunks for a document.
- `match_chunks(query_embedding: list[float], match_threshold: float = 0.7, match_count: int = 20) -> list[dict]`: Calls the `match_chunks` RPC function. Returns list of dicts with chunk_id, doc_id, content, metadata, similarity.

Create `pageindex/db/trees.py` with tree operations:
- `insert_tree(doc_id: str, tree_json: dict) -> dict`: Inserts a tree for a document. Uses upsert (on conflict doc_id, update tree_json) so re-indexing a document replaces its tree. Returns inserted/updated row.
- `get_tree(doc_id: str) -> dict | None`: Gets the tree for a document. Returns None if not found.

All modules import `get_client` from `pageindex.db.client`. All functions call `.execute()` on Supabase queries and return `.data` from the response. Handle the Supabase `APIError` exception for error cases.

Do NOT add `supabase` to requirements.txt in this plan -- that happens in Plan 02 alongside `litellm` to keep requirements.txt updates in one place.
  </action>
